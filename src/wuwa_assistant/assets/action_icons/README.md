# 动作图标来源

本目录的通用动作与键鼠图标取自 [NovaWallace/wwcombo](https://github.com/NovaWallace/wwcombo) 的 `public/combo-assets/button-icons`，用于把结构化动作映射为悬浮窗图标。

- 许可证副本：[`../../../../third_party/WWCOMBO-MIT.txt`](../../../../third_party/WWCOMBO-MIT.txt)
- 上游版权：Copyright (c) 2026 NovaWallace

`icon_mappings.json` 由本项目维护，用于将语义动作、文字轴记号与图标文件分离。
