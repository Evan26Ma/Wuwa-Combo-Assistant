# 鸣潮零额外按键逐键教练

一个 Windows 悬浮连招提示器。它只读取你配置的游戏键位状态，不拦截、不修改、也不向游戏发送任何输入。

## 已内置的连招

- 卡夏千：启动轴执行一次，随后自动进入并重复循环轴
- 秧千穗：28 秒启动轴执行一次，随后自动进入约 25.3 秒循环轴

连招顺序来自用户指定的两段教学视频。程序只识别按键并提示下一步，不判断动画命中、落地时机或操作早晚。

每个逐键节点还会显示基于 OK-WW 角色控制代码整理的操作建议，包括三剑/Forte3/协奏等资源用途、技能优先级、落地与切人注意事项。建议只解释当前视频按键，不会替换视频轴或自动操作；规则来源见 [`docs/OKWW_OPERATION_RULES.md`](docs/OKWW_OPERATION_RULES.md)。

## 使用方法

1. 双击 `dist\鸣潮逐键教练.exe`。
2. 首次启动会进入控制台的键位设置页，确认实际游戏键位后保存。
3. 进入鸣潮后，控制台会根据你的真实游戏输入自动推进。
4. 正常实战无需任何脚本热键。需要调试时，右击悬浮窗或使用系统托盘菜单。

队伍选择、键位设置、提示设置、画面识别、使用帮助和关于都已集成在同一个控制台中，不会再打开旧版设置窗口。
战斗时会显示完全透明的置顶悬浮提示，只保留当前角色名和下一按键；切出鸣潮后自动隐藏。
连招记号使用 `A` 表示左键普攻、`Z` 表示长按左键重击；这不会改变实际游戏键位。
点击悬浮提示右上角的“全部按键”，或打开控制台左侧“完整按键轴”，可查看启动轴与循环轴的全部步骤。

### 视觉校准

视觉识别是可选的增强信号。在“画面识别”页设置 ROI 后，把游戏切到需要采集的角色/HUD 状态，再保存角色模板。视觉分数不会阻止连招推进。

程序已内置 12 项稳定 HUD 模板：卡提希娅、夏空、千咲、秧秧、穗穗角色识别，卡提三剑/形态/空中攻击/终结大招，以及穗穗 Forte3。首次运行会自动安装到 `%APPDATA%` 并启用；识别结果仅用于提示、角色同步和锚点评分，不会阻止按键推进。本机安装了 OK-WW 时，仍可在“画面识别”页重新导入更新模板。

控制台已内置卡提希娅、夏空、千咲、秧秧和穗穗的 HUD 头像，用于队伍卡片和队伍选择页，无需安装 OK-WW。若本机存在 OK-WW，程序仍会把重新提取的头像缓存到 `%APPDATA%\WuwaComboAssistant\okww-assets` 并优先使用。素材来源和许可见 [`src/wuwa_assistant/assets/portraits/README.md`](src/wuwa_assistant/assets/portraits/README.md)。

仓库附带 [`wuwa-teaching-link-to-combo`](skills/wuwa-teaching-link-to-combo/SKILL.md) Skill。安装后只需提供鸣潮教学链接，即可按固定流程提取启动轴、循环轴、逐键条件、OK-WW 建议、识图锚点并完成测试与 EXE 构建。

## 从源码运行

```powershell
python -m pip install -r requirements.txt
.\run.ps1
```

## 构建独立 EXE

```powershell
.\build.ps1
```

构建脚本会先安装开发依赖、运行测试，再生成 `dist\鸣潮逐键教练.exe`。

## 隐私与风险说明

- 程序完全离线，不上传截图、模板或按键记录。
- 程序只轮询配置中的少量键位，不安装低级键盘钩子。
- 源码中没有输入注入接口。
- 第三方辅助工具可能受游戏服务条款限制；使用前请自行确认当前规则。
- 未签名 EXE 首次运行时可能触发 Windows SmartScreen 提示。
