# 教学视频分析

## 证据优先级

1. 作者简介、置顶评论或画面中的文字轴。
2. 作者字幕和明确口播。
3. 带按键显示器的实机演示。
4. 仅凭角色动画推断；只能标为参考。

## 提取内容

- 视频 URL、标题、作者和引用时间点。
- 队伍三人及游戏槽位顺序。
- 启动轴、循环轴、可选分支与循环返回点。
- 每一步的角色、按键、小段名和动作条件。
- 长按、跳跃、闪避取消、下落、落地、变奏、延奏和资源条件。
- 能稳定识别的角色 HUD、资源图标或技能形态。

## 浏览步骤

- 链接来自现有 Chrome 标签页或需要登录状态时使用 Chrome 控制能力；否则使用应用内浏览器。
- 先读取页面文本、简介和字幕，再查看关键时间点截图。不要只凭标题生成轴。
- 页面无字幕时查看简介、评论和画面文字；仍缺关键顺序时向用户说明具体缺口。
- 不下载或转载整段视频。只记录实现所需的事实、短摘录和时间点。

## 拆轴规则

- 启动轴：开战后只执行一次的铺垫、首次资源建立和首次变奏链。
- 循环轴：从稳定返回点开始，到再次回到同一角色/资源状态结束。
- 分支：只在视频明确给出时加入。项目当前状态机以确定序列为主，无法可靠识别的可选键应标注并配置锚点恢复。
